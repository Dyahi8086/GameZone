GAMEZONE 3D — Android/GitHub Pages setup

1. ZIP ko download karke extract karein.
2. GitHub par apna GameZone repository kholein.
3. Ek naya folder banayein: gamezone-3d
4. Is ZIP ke chaaron files us folder mein upload karein.
5. GitHub Pages URL par ye folder khulega:
   https://dyahi8086.github.io/GameZone/gamezone-3d/
6. Agar direct URL par 404 aaye, repository Settings > Pages mein deployment successful hone ka wait karein.

IMPORTANT:
- Ye prototype procedural Three.js geometry use karta hai. 3D car aur portals code se bante hain; external 3D model download ki zaroorat nahi.
- Ismein zone menus aur game launch slots hain. Real playable HTML5 games abhi connect nahi kiye gaye; game tiles filhaal placeholders hain.
- Three.js aur Google Fonts internet se load hote hain, isliye online connection chahiye.
- Main website ki files ko overwrite na karein. Pehle naya folder test karein.
